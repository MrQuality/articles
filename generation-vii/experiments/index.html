Unsigned 64-bit resource admission

Download the SMT-LIB model and run it with Z3. The article used Z3 4.13.3.

z3 admission.smt2

The recorded Z3 4.13.3 run returns SAT for the wrapping predicate and the article's concrete witness, and UNSAT for the guarded predicate.

Combining two scheduler changes

Download the state explorer and run it with Python 3.10 or later.

python evolution_model.py

Compare your output with the recorded run. Only the combined changes violate the invariant in this model.

Checking evidence before admission

Download the admission model alongside the state explorer and run it with Python 3.10 or later.

python admission_model.py

Compare the output with the recorded decisions. Single-worker evidence is rejected when a proposed change introduces two workers. Re-verification finds a violation and rejects the combined configuration.
