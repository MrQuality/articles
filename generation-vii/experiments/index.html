Unsigned 64-bit resource admission

Download the SMT-LIB model and run it with Z3. The article used Z3 4.13.3.

z3 admission.smt2

Expected results are SAT for the wrapping predicate and the article's concrete witness, and UNSAT for the guarded predicate.

Combining two scheduler changes

Download the state explorer and run it with Python 3.10 or later.

python evolution_model.py

Compare your output with the recorded run. Only the combined changes violate the invariant in this model.
